Rust log formatters

For each logger configuration, the same five format-string variants — {}, {:?}, {:#?}, {name}, and other specs — rendered as call site (top) and captured output (bottom).

Do log and tracing share the same format?

No. Switch between the env_logger and tracing-subscriber tabs to see the difference in defaults. The tracing-log bridge tab shows what log::info! looks like when routed through tracing-subscriber.

Initialized with env_logger::init().

log::info!("hello {}, the answer is {}", "world", 42);
[2026-05-07T18:49:31Z INFO  env_logger_default] hello world, the answer is 42

{:?} — Debug

let users = vec!["alice", "bob", "charlie"];
log::info!("users: {:?}", users);
[2026-05-07T18:49:31Z INFO  env_logger_default] users: ["alice", "bob", "charlie"]

{:#?} — pretty Debug

#[derive(Debug)]
struct User { name: &'static str, age: u32, roles: Vec<&'static str> }

let user = User { name: "alice", age: 30, roles: vec!["admin", "editor"] };
log::info!("user: {:#?}", user);
[2026-05-07T18:49:31Z INFO  env_logger_default] user: User {
        name: "alice",
        age: 30,
        roles: [
            "admin",
            "editor",
        ],
    }

{name} — implicit named-argument capture (Rust 2021+)

let name = "alice";
let age = 30;
log::info!("user {name} is {age} years old");
[2026-05-07T18:49:31Z INFO  env_logger_default] user alice is 30 years old

{:x}, {:>5}, {:.2}, {:08b} — width, precision, hex, binary

let n = 255u32;
log::info!("hex={:x}  padded={:>5}  precision={:.2}  binary={:08b}", n, n, 3.14159, n);
[2026-05-07T18:49:31Z INFO  env_logger_default] hex=ff  padded=  255  precision=3.14  binary=11111111
