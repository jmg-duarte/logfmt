Do log and tracing share the same format?

No. Switch between the env_logger and tracing-subscriber tabs to see the difference in defaults. The tracing-log bridge tab shows what log::info! looks like when routed through tracing-subscriber.

Default formatter, called as env_logger::init().

    env_logger::init();
    log::info!("the answer was: {}", 12);
}

log::info! routed through tracing-subscriber via tracing_log::LogTracer. Output uses tracing's format, not env_logger's.

fn main() {
    tracing_log::LogTracer::init().expect("LogTracer init");
    let subscriber = tracing_subscriber::fmt().finish();
    tracing::subscriber::set_global_default(subscriber).expect("set global default");
    log::info!("the answer was: {}", 12);
}
2026-05-07T18:26:00.484863Z  INFO tracing_log_bridge: the answer was: 12
